Phishing Guard – Demo-Seite

Mit laufendem Backend und geladener Extension sollten die Links unten entsprechend markiert sein. Keiner dieser Links wird aufgerufen – nur die Adresse wird bewertet. Die „gefährlichen“ Adressen sind ausgedacht.

Sollten unauffällig bleiben

  • Wikipedia
  • File Integrity Monitor auf GitHub
  • Sparkasse (echt)
  • PayPal Login (echt)
  • Hochschule Darmstadt
  • Gmail-Redirect zur Tagesschau

Sollten verdächtig oder gefährlich sein

  • Ihr PayPal-Konto bestätigen – Lookalike-Domain
  • Sparkasse: Konto verifizieren – Marke + verdächtige TLD
  • Online-Banking – IP-Adresse als Host
  • Amazon Konto-Update – Marke in der Subdomain
  • DHL Sendung verfolgen – Paket-Masche
  • Gmail-Redirect zu Phishing – Wrapper wird ausgepackt
  • Punycode-Domain
  • Gekürzter Link – Ziel unbekannt
